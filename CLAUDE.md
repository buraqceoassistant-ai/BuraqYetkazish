# BURAQ logistics — сайт отгрузок и планов

Фирменный стиль — обязателен для всего видимого (цвета, шрифт, логотип, кнопки, иконки):

@buraq-brand/BRAND.md
@buraq-brand/DESIGN-GLASS.md

- Цвета сайта — токены в `css/design-system.css` (`--buraq-*`, `--color-*`); новых цветов в разметку не добавлять.
  Есть тёмная тема (`css/glass-dark.css` переопределяет токены под `:root[data-theme="dark"]`) — новое проверять в
  обеих темах; цвета только через токены, тогда они верны в обеих.
- Логотип — только файлы из `buraq-brand/logo/` (на синем — `buraq-logo-white.svg`, на светлом — `buraq-logo.svg`).
- Шрифт — Neue Montreal из `fonts/` (только латиница; кириллица и числа в столбцах — Inter), заголовки капсом обычной
  толщины.
- Интерфейс для сотрудников — на русском и узбекском: код пишет по-русски, узбекский — словарь `tools/i18n/uz.txt`
  (новые надписи добавлять туда же, затем `node tools/build-i18n.mjs`; см. README, «Язык сайта»). Тексты для
  клиентов — на узбекском латиницей (см. BRAND.md).
