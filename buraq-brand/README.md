# BURAQ Logistics — пакет фирменного стиля

Загрузи эту папку (или zip) в Claude, ChatGPT, Cursor или любой другой инструмент — и у него будет всё, чтобы делать материалы в стиле BURAQ.

## Что читать первым

1. `BRAND.md` — правила бренда: логотип, 5 цветов, шрифт, графические приёмы, слоганы, услуги, контакты.
2. `DESIGN-GLASS.md` — как бренд выглядит в стиле glassmorphism (стеклянные панели на тёмно-синем фоне).
3. `brandbook.html` — готовый бренд-бук, открывается в браузере без интернета. Пример того, как всё должно выглядеть.

## Файлы

```
buraq-brand/
├── README.md           этот файл
├── BRAND.md            правила бренда (главный документ)
├── DESIGN-GLASS.md     стеклянный стиль: фон, панели, текст, элементы
├── tokens.css          цвета и шрифт в CSS-переменных
├── glass.css           готовые классы стеклянного стиля (подключать после tokens.css)
├── brandbook.html      бренд-бук, самостоятельный файл
└── logo/
    ├── buraq-logo.svg        основной: синий + красный (на белом)
    ├── buraq-logo-white.svg  белый (на синем, красном, тёмном фото)
    ├── buraq-logo-navy.svg   тёмно-синий (на сером)
    ├── *.png                 те же логотипы, 2000 px, прозрачный фон
    └── logo-preview.png      какой логотип на каком фоне
```

## Готовый промпт для нейросети

> Прочитай `buraq-brand/BRAND.md` и `buraq-brand/DESIGN-GLASS.md` и соблюдай их. Цвета только из `tokens.css`, логотипы только из `buraq-brand/logo/`. Оформление — glassmorphism, как в `brandbook.html`: тёмно-синий фон с размытыми синим и красным пятнами, стеклянные панели, заголовки капсом обычной толщины, красные тонкие стрелки. Тексты для клиентов — на узбекском языке латиницей.

## Для Claude Code / Cursor

Положи папку `buraq-brand/` в корень проекта и добавь в `CLAUDE.md` (или `.cursorrules`):

```
@buraq-brand/BRAND.md
@buraq-brand/DESIGN-GLASS.md
```
