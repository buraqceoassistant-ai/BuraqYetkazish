Google Таблица

Таблица становится главной: новые партии, клиенты и склады из неё сами появляются на сайте, а правки на сайте записываются в неё. Формулы, планы и листы остаются в таблице. Ссылка сохраняется для всех устройств: телефон и компьютер после входа работают с одной таблицей.
{{ gsWhere }}
  1. Откройте вашу Google Таблицу → меню Расширения → Apps Script.
  2. Удалите всё в редакторе, вставьте код ниже и нажмите Сохранить.
  3. Развернуть → Новое развертывание → шестерёнка → Веб-приложение. «Выполнять как»: Я, «Доступ»: Все → Развернуть → разрешите доступ к аккаунту.
    Если скрипт уже подключён и нужно обновить код: вставьте новый код → Развернуть → Управление развертываниями → ✎ → Версия: новая → Развернуть. Ссылка останется прежней.
    С версии 19 скрипт без пароля закрыт. До обновления кода: Apps Script → ⚙ Настройки проекта → Свойства скрипта → TOKEN = пароль скрипта (как в поле «Пароль скрипта» ниже) и EDITOR_TOKEN = секрет редактора (ниже, «ИИ-импорт манифестов» → «Показать секрет») → «Сохранить свойства скрипта». Иначе новый код не пустит сайт.
  4. Скопируйте ссылку веб-приложения (заканчивается на /exec) и вставьте сюда:
Сайт пишет «Скрипт таблицы не отвечает» — что делать
Откройте ссылку веб-приложения (…/exec) в браузере — кнопка «Открыть скрипт» в полосе над страницей. Что там написано:
  • Короткий ответ со словами error и v — скрипт работает (например, «Неверный пароль» и номер версии). Нажмите «Отправить снова»; не помогло — проверьте интернет.
  • «Требуется авторизация» (Authorization is required) — в Apps Script выберите вверху функцию authorize → ▶ Выполнить → разрешите доступ, отметьте все галочки.
  • Вход в Google или «Нет доступа» — Развернуть → Управление развертываниями → ✎ → «У кого есть доступ»: «Все» → Развернуть.
  • «Не удалось открыть файл» или «Страница не найдена» — ссылка устарела: развертывание удалили или создали новое. Развернуть → Управление развертываниями → скопируйте ссылку действующего (…/exec) и вставьте ниже.
  • Ошибка с текстом (TypeError, ReferenceError, SyntaxError…) — код вставлен не полностью: «Скопировать код» → в Apps Script удалите всё → вставьте → Сохранить → Развернуть → Управление развертываниями → ✎ → Версия: новая.
